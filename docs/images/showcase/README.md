# Showcase credits and capture notes

These images were supplied for the README and show models from
[glTF-Sample-Assets](https://github.com/KhronosGroup/glTF-Sample-Assets).
The image files' names and visible usdview window titles identify the variants
below. The source checkout commit, plugin and OpenUSD versions, GPU, launch
commands, and capture or post-processing settings are not recorded; do not
assume these captures correspond to a particular release. The visible renderer
is Hydra Storm with OpenGL. Stage hierarchy and appearance can vary with the
plugin version, renderer, and settings. See the
[capability matrix](../../reference/CAPABILITY_MATRIX.md) for verified scope
and limitations.

Model licenses apply to the depicted models and may differ from the project
license. Consult the linked upstream legal information before reuse.
