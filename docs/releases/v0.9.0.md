# v0.9.0 - Static node visibility

- **Tag** `v0.9.0`
- **Date** 2026-11-16
- **Release** [v0.9.0](https://github.com/animu-sphere/usd-gltf-plugins/releases/tag/v0.9.0)

The importer supports static `KHR_node_visibility` in glTF and GLB. An invisible node hides its
meshes and punctual lights and those of its descendants. Cameras below it remain usable in Storm.
See the [changelog](../../CHANGELOG.md#090---2026-11-16).

## Compatibility and limits

- Packages target the pinned OpenStrata `cy2026` / `usd` runtimes on Windows x86-64, Linux x86-64
  and macOS arm64 with OpenUSD 26.08 and Python 3.13.
- Optional `KHR_animation_pointer` channels are ignored with a warning. The importer keeps the
  static visibility values. See the [node visibility decision](../adr/0036-node-visibility.md).

## Verification observed

On Windows x86-64 with OpenUSD 26.08, Storm verified inherited mesh visibility, punctual light
contribution, and rendering through a camera under a hidden node in both shader paths. All six
CubeVisibility, LightVisibility and NodeVisibilityTest files drew through both paths and matched
their source's static visibility. See the [display checks](../reference/CAPABILITY_MATRIX.md#display-checks)
and [sample check](../reference/CAPABILITY_MATRIX.md#sample-assets).

The [release gate](../roadmap/README.md#release-gate) repeats the display and sample checks at the
commit to be tagged. The GitHub release provides package pins and checksums.
