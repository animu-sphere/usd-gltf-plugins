# v0.3.0 - scene graph, animation and deformation

- **Tag** `v0.3.0`
- **Date** 2026-11-11
- **Release** [v0.3.0](https://github.com/animu-sphere/usd-gltf-plugins/releases/tag/v0.3.0)

The importer preserves the selected scene's node hierarchy and authors node animation, skins,
skeletal animation and morph targets. Choose one glTF animation through the `animation` variant set
on `/Root`. The default is `Animation_0`, and each variant keeps its node, joint and morph weight
channels together. The [changelog](../../CHANGELOG.md#030---2026-11-11) lists the changes, and the
[capability matrix](../reference/CAPABILITY_MATRIX.md) records the supported subset and its evidence.

## Prim path migration

| v0.2.0 path | v0.3.0 path |
| --- | --- |
| `/Asset` | `/Root` (default prim) |
| `/Asset/geo` | `/Root/Scenes/Scene_{index}` |
| `/Asset/geo/Node_3/Mesh_0` | `/Root/Scenes/Scene_0/Node_3/Mesh_0` for scene 0 |
| `/Asset/mtl` | `/Root/Materials` |

Use the selected glTF scene's index and update explicit reference targets, overrides, collections
and relationships. For a reference composed under a host prim, update its relative paths such as
`geo/Node_3` to `Scenes/Scene_0/Node_3`. Implicit default-prim references resolve to the new root.
Some glTF joint nodes are represented as skeleton joints. See the
[scene conventions](../design/SCENE_CONVENTIONS.md#structure-and-names) for their placement.

## Compatibility and limits

- Packages target OpenStrata `cy2026` / `usd` on Windows x86-64, Linux x86-64 and macOS arm64 with
  OpenUSD 26.08 and Python 3.13. Use the exact runtime pinned for each package. Import is read-only.
- Node and joint animation support LINEAR, STEP and sampled CUBICSPLINE. Near-identity USD
  orientation interpolation and half-precision joint scales can affect the resulting pose.
  Cameras and lights require transforms whose scale correction remains valid over the clip.
- Morph targets support POSITION and NORMAL deltas. TANGENT deltas and invalid samplers are
  rejected with diagnostics. Sparse accessors are supported for morph deltas and weight outputs
  within the documented subset. UsdSkel bounds can underestimate a scaled morphing node under
  a shared skel root.
- A mesh used by several nodes is converted once and copied to each placement. Geometry exists
  at its scene placements only. The [capability matrix](../reference/CAPABILITY_MATRIX.md)
  records the existing material, image and resource resolution limits.

## Verification observed

On Windows x86-64 with MSVC, OpenUSD 26.08 and an NVIDIA RTX A5000, the scene and animation candidate
passed 10 CTest tests and 681 Storm fixture comparisons through MaterialX and UsdPreviewSurface.
All 339 Khronos samples at `8f49239` matched the baseline for opening and USD data, including
animated world transforms across variants. Storm sample rendering checks coverage at a static
frame. See the [display checks](../reference/CAPABILITY_MATRIX.md#display-checks) and
[sample assets](../reference/CAPABILITY_MATRIX.md#sample-assets) for the environment and results.

The [release gate](../roadmap/README.md#release-gate) repeats the display and sample checks at the
