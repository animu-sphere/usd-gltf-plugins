# v0.13.0 - Core geometry gaps

- **Tag** `v0.13.0`
- **Date** 2026-11-21
- **Release** [v0.13.0](https://github.com/animu-sphere/usd-gltf-plugins/releases/tag/v0.13.0)

The importer reads sparse accessors and accessors without a bufferView wherever it reads accessor
data, not only in morph targets and weights. It also imports morph target TANGENT deltas, which it
keeps on each blend shape as `gltf:tangentOffsets`. No Khronos sample file is now rejected for
either. See the [changelog](../../CHANGELOG.md#0130---2026-11-21) and the
[morph tangent decision](../adr/0041-morph-target-tangents.md).

## Compatibility and limits

- Packages target the pinned OpenStrata `cy2026` / `usd` runtimes on Windows x86-64, Linux x86-64
  and macOS arm64 with OpenUSD 26.08 and Python 3.13.
- The zeros of an accessor without a bufferView count against the 512 MiB per-import budget for data
  the file does not store, which decoded meshopt views share. Draco attributes and indices must not
  be sparse.
- UsdSkel has no tangent offsets and does not apply `gltf:tangentOffsets`, so `gltf_tangent` stays
  the base frame. Neither shading network reads it, so nothing drawn changes. A consumer that needs
  the morphed frame computes it. See the
  [scene conventions](../design/SCENE_CONVENTIONS.md#tangents).
- Points and lines, the archived `KHR_materials_pbrSpecularGlossiness` and the unratified
  `KHR_meshopt_compression` are still rejected.

## Verification observed

On Windows x86-64 with OpenUSD 26.08, both SimpleSparseAccessor files and both AnimatedMorphCube
files open, agree with values decoded from the glTF, and draw through MaterialX and
UsdPreviewSurface in Storm. Of the 339 sample files, 331 open and 8 are rejected, each for a cause it
has. See the [sample check](../reference/CAPABILITY_MATRIX.md#sample-assets).

The [release gate](../roadmap/README.md#release-gate) repeats the checks at the commit to be
tagged. The GitHub release provides package pins and checksums.
