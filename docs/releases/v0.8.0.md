# v0.8.0 - Emissive strength

- **Tag** `v0.8.0`
- **Date** 2026-11-15
- **Release** [v0.8.0](https://github.com/animu-sphere/usd-gltf-plugins/releases/tag/v0.8.0)

The importer supports `KHR_materials_emissive_strength` in glTF and GLB. It preserves the multiplier
in MaterialX and applies it to emissive color and texture scale in UsdPreviewSurface. See the
[changelog](../../CHANGELOG.md#080---2026-11-15).

## Compatibility and limits

- Packages target the pinned OpenStrata `cy2026` / `usd` runtimes on Windows x86-64, Linux x86-64
  and macOS arm64 with OpenUSD 26.08 and Python 3.13.
- The extension scales surface emission. HDR output, bloom and lighting from emissive surfaces
  depend on the renderer. The [emissive strength decision](../adr/0035-emissive-strength.md)
  describes the mapping and display limits.

## Verification observed

On Windows x86-64 with OpenUSD 26.08, both shader paths agreed with equivalent emission controls
in Storm. The PlaysetLightTest glTF and GLB opened, their authored values agreed with the source,
and both drew through each shader path. See the [display checks](../reference/CAPABILITY_MATRIX.md#display-checks)
and [sample check](../reference/CAPABILITY_MATRIX.md#sample-assets).

The [release gate](../roadmap/README.md#release-gate) repeats the display and sample checks at the
commit to be tagged. The GitHub release provides package pins and checksums.
