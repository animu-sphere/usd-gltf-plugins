# v0.16.0 - Animated material properties

- **Tag** `v0.16.0`
- **Date** 2026-11-23
- **Release** [v0.16.0](https://github.com/animu-sphere/usd-gltf-plugins/releases/tag/v0.16.0)

The importer reads `KHR_animation_pointer` channels to material properties: the factors, alpha
cutoff, normal scale and occlusion strength of the core material and of each supported material
extension, and the offset, rotation and scale of `KHR_texture_transform` on every texture slot. Each
input's value at a time is the static conversion of the material with the channels' values then,
authored as time samples in the `animation` variants of both shader networks. No Khronos sample file
now ignores a channel to a material property that the importer authors. See the
[changelog](../../CHANGELOG.md#0160---2026-11-23) and the
[animated material properties decision](../adr/0044-animated-material-properties.md).

## Compatibility and limits

- Packages target the pinned OpenStrata `cy2026` / `usd` runtimes on Windows x86-64, Linux x86-64
  and macOS arm64 with OpenUSD 26.08 and Python 3.13.
- An animated material input has its value only inside the `animation` variants. A selection that
  names no variant leaves it at the shader's own default, without a diagnostic.
- An animated texture transform is authored even where its stated fields are all defaults. The
  translation that an animated rotation moves is sampled in pieces, within 1e-4 of the texture's size,
  so it has on the order of a hundred time samples per keyframe segment.
- UsdPreviewSurface keeps the stated base color factor on primitives with COLOR_0, with a warning;
  MaterialX animates it.
- Channels to diffuse transmission, to lit properties of unlit materials, to a cutoff outside `MASK`,
  and channels that repeat another, are ignored with a warning. An animated ior or cutoff of 0, and
  an animated attenuation distance whose stated value is infinite, are unsupported.
- Display over time was checked with Storm only, at whole time codes. Other renderers may not update
  material inputs over time.
- The archived `KHR_materials_pbrSpecularGlossiness` and the unratified `KHR_meshopt_compression`
  are still rejected.

## Verification observed

On Windows x86-64 with OpenUSD 26.08, AnimatedColorsCube, PotOfCoalsAnimationPointer and
AnimationPointerUVs, apart from its diffuse transmission channels, match the source's base color
factors and texture transforms at every keyframe, inside each segment and outside the range, in every
USD material made from each animated glTF material. Of the 339 sample files, 334 open and 5 are
rejected, each for a cause it has; 315 have their meaning verified. See the
[sample check](../reference/CAPABILITY_MATRIX.md#sample-assets). The
[display check](../reference/CAPABILITY_MATRIX.md#display-checks) passed 993 comparisons, including
material inputs drawn over time through both shader paths.

The [release gate](../roadmap/README.md#release-gate) repeats the checks at the commit to be
tagged. The GitHub release provides package pins and checksums.
