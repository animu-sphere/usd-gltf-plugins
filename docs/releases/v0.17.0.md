# v0.17.0 - XMP metadata

- **Tag** `v0.17.0`
- **Date** 2026-11-23
- **Release** [v0.17.0](https://github.com/animu-sphere/usd-gltf-plugins/releases/tag/v0.17.0)

The importer reads `KHR_xmp_json_ld`. Each packet is the dictionary `assetInfo["xmp"]` of every prim
made from an object that references it: the asset's on `/Root`, the default prim, and the selected
scene's, nodes', each mesh placement's, every USD material's and the texture nodes that read an image.
An animation's packet is in `customData["gltf"]["xmp"]` inside its variant. No Khronos sample file now
ignores the extension. See the [changelog](../../CHANGELOG.md#0170---2026-11-23) and the
[XMP metadata decision](../adr/0045-xmp-metadata.md).

## Compatibility and limits

- Packages target the pinned OpenStrata `cy2026` / `usd` runtimes on Windows x86-64, Linux x86-64
  and macOS arm64 with OpenUSD 26.08 and Python 3.13.
- Values keep their JSON-LD form, with compact IRIs such as `"dc:title"` as keys, so
  `GetAssetInfoByKey` key paths do not reach inside a packet; read `GetAssetInfoByKey("xmp")` whole.
  `null` and arrays of objects, arrays or mixed types are JSON literals, with a warning.
- A packet below `/Root` describes only its own object. Objects without prims keep no packet, and a
  joint without a prim warns.
- The extension cannot be required, and malformed packets or references fail the import. Prefixes
  and the specification's other JSON-LD restrictions are not checked. The archived `KHR_xmp` is still
  ignored.
- The archived `KHR_materials_pbrSpecularGlossiness` and the unratified `KHR_meshopt_compression`
  are still rejected.

## Verification observed

On Windows x86-64 with OpenUSD 26.08, both XmpMetadataRoundedCube files and both ScatteringSkull files
have each packet on the prims of the objects that reference it, and on no other prim. Of the 339
sample files, 334 open and 5 are rejected, each for a cause it has; 317 have their meaning verified.
See the [sample check](../reference/CAPABILITY_MATRIX.md#sample-assets). The
[display check](../reference/CAPABILITY_MATRIX.md#display-checks) passed 993 comparisons;
metadata is not drawn.

The [release gate](../roadmap/README.md#release-gate) repeats the checks at the commit to be
tagged. The GitHub release provides package pins and checksums.
