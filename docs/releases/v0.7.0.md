# v0.7.0 - Meshopt compression

- **Tag** `v0.7.0`
- **Date** 2026-11-15
- **Release** [v0.7.0](https://github.com/animu-sphere/usd-gltf-plugins/releases/tag/v0.7.0)

The importer decodes `EXT_meshopt_compression` buffer views for meshes and animation and
reuses the decoded bytes across accessor reads in the same import. See the
[changelog](../../CHANGELOG.md#070---2026-11-15).

## Compatibility and limits

- Packages target the pinned OpenStrata `cy2026` / `usd` runtimes on Windows x86-64, Linux x86-64
  and macOS arm64 with OpenUSD 26.08 and Python 3.13.
- The importer supports the EXT bitstream via meshoptimizer 0.25. Invalid compressed views fail
  even when an optional fallback is present. `KHR_meshopt_compression` remains unsupported. See
  the [meshopt decision](../adr/0034-meshopt-buffer-views.md) for the supported modes, filters and bounds.

## Verification observed

On Windows x86-64 with OpenUSD 26.08, BrainStem's mesh and animation data and DragonAttenuation's
mesh data agreed with the independent JavaScript reference decoder. Both compressed files drew
through both Storm shader paths. The [sample check](../reference/CAPABILITY_MATRIX.md#sample-assets)
records the comparison scope and the optional material extension used by DragonAttenuation.

On Windows, two packaging runs produced the same digest. The extracted bundle passed the
package check for Draco and Meshopt meshes, KTX2 images and third-party notices.

The [release gate](../roadmap/README.md#release-gate) repeats the display and sample checks at the
commit to be tagged. The GitHub release provides package pins and checksums.
