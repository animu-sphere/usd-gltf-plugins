# v0.6.0 - Tangent frames

- **Tag** `v0.6.0`
- **Date** 2026-11-15
- **Release** [v0.6.0](https://github.com/animu-sphere/usd-gltf-plugins/releases/tag/v0.6.0)

The importer generates mesh-local MikkTSpace tangents for triangle primitives whose materials
need a tangent frame when a supplied frame cannot be used. The generated USD primvar stores a
tangent and handedness at each face corner, including mirrored UV seams. See the
[changelog](../../CHANGELOG.md#060---2026-11-15).

## Compatibility and limits

- Packages target the pinned OpenStrata `cy2026` / `usd` runtimes on Windows x86-64, Linux x86-64
  and macOS arm64 with OpenUSD 26.08 and Python 3.13.
- MaterialX and UsdPreviewSurface use renderer-derived frames. Shading can differ from glTF
  for explicit tangents and for anisotropy on mirrored UVs. Generated tangents describe the
  base mesh. See the [tangent frame decision](../adr/0004-normal-textures-and-tangents.md#tangents).

## Verification observed

On Windows x86-64 with OpenUSD 26.08 and MaterialX 1.39.5, the authored tangents and handedness
agreed with the Khronos Sample Renderer's MikkTSpace Wasm in the three generated cases. The
[capability matrix](../reference/CAPABILITY_MATRIX.md#tangent-frame-comparison) records the Storm
comparison for supplied and generated tangents.

The [release gate](../roadmap/README.md#release-gate) repeats the display and sample checks at the
commit to be tagged. The GitHub release provides package pins and checksums.
