# v0.10.0 - Animated node visibility

- **Tag** `v0.10.0`
- **Date** 2026-11-16
- **Release** [v0.10.0](https://github.com/animu-sphere/usd-gltf-plugins/releases/tag/v0.10.0)

The importer reads `KHR_animation_pointer` channels that animate node visibility in glTF and GLB.
Switch animation clips with the `animation` variant set on `/Root`. Meshes and punctual lights
follow the visibility of their ancestors at each STEP keyframe; cameras remain usable.
See the [changelog](../../CHANGELOG.md#0100---2026-11-16).

## Compatibility and limits

- Packages target the pinned OpenStrata `cy2026` / `usd` runtimes on Windows x86-64, Linux x86-64
  and macOS arm64 with OpenUSD 26.08 and Python 3.13.
- The supported pointer is `/nodes/{index}/extensions/KHR_node_visibility/visible`. Other targets
  warn and are skipped for an optional declaration, or reject the file for a required declaration.
  See the [animated visibility decision](../adr/0037-animated-node-visibility.md).

## Verification observed

On Windows x86-64 with OpenUSD 26.08, both glTF and GLB versions of CubeVisibility and
LightVisibility match the source visibility keys and their transitions. Storm checked geometry,
punctual light contribution, and camera access before and at the changes through both shader paths.
See the [sample check](../reference/CAPABILITY_MATRIX.md#sample-assets) and
[display checks](../reference/CAPABILITY_MATRIX.md#display-checks).

The [release gate](../roadmap/README.md#release-gate) repeats the checks at the commit to be
tagged. The GitHub release provides package pins and checksums.
