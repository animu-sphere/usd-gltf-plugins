# v0.5.0 - Draco mesh compression

- **Tag** `v0.5.0`
- **Date** 2026-11-13
- **Release** [v0.5.0](https://github.com/animu-sphere/usd-gltf-plugins/releases/tag/v0.5.0)

The importer opens glTF triangle meshes compressed with `KHR_draco_mesh_compression`.
It authors the decoded vertex attributes and triangle indices through the same USD mesh path
used by uncompressed glTF. See the [changelog](../../CHANGELOG.md#050---2026-11-13).

## Compatibility and limits

- Packages target the pinned OpenStrata `cy2026` / `usd` runtimes on Windows x86-64, Linux x86-64
  and macOS arm64 with OpenUSD 26.08 and Python 3.13.
- A compressed `TRIANGLE_STRIP` can use its uncompressed fallback when the extension is optional.
  Required strips and corrupt Draco triangle payloads fail with a diagnostic. The
  [decoder decision](../adr/0033-draco-decoder.md) gives the mapping and the measured package sizes.

## Verification observed

On Windows x86-64 with OpenUSD 26.08, the authored meshes for all 18 Draco-compressed Khronos
samples agreed with the upstream Wasm decoder. Each sample drew through both Storm shader paths.
The release dry run built the Draco-enabled bundles and verified their extracted packages on all
three targets. The [capability matrix](../reference/CAPABILITY_MATRIX.md) records the integration,
package and sample checks.

The [release gate](../roadmap/README.md#release-gate) repeats the display and sample checks at the
commit to be tagged. The GitHub release provides package pins and checksums.
